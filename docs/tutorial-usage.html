Dokumen ini menjelaskan secara lengkap cara menggunakan aplikasi Web Admin dan Aplikasi Android untuk pengelolaan inspeksi pencegahan dan pengendalian infeksi (PPI) di lingkungan rumah sakit — mulai dari login, pengelolaan data master, alur persetujuan inspeksi, hingga analitik kinerja.

1. Memulai

Cara mengakses aplikasi dan akun default

🌐 Cara Mengakses

  • Web Admin (untuk Admin PPI & Supervisor) — buka di browser komputer, contoh: http://localhost:8080 atau alamat server yang sudah disediakan pihak IT.
  • Aplikasi Android (untuk Inspector di lapangan) — install aplikasi dari file .apk yang dibagikan tim IT, lalu isi alamat server saat pertama kali dibuka.
  • Disarankan menggunakan Chrome / Edge / Firefox versi terbaru agar semua fitur berjalan optimal.

🔑 Akun Default (Setelah Instalasi / Seed Data)

Setelah database di-seed, tersedia 3 akun percobaan:

adminadmin123Admin PPI
supervisorsupervisor123Supervisor
inspectorinspector123Inspector
⚠️
Penting! Segera ganti password default setelah login pertama kali melalui menu Ganti Password di pojok kanan atas. Password default hanya untuk keperluan demo/pengujian.

2. Peran & Hak Akses

Tiga peran pengguna dengan kewenangan berbeda
Admin PPI
admin_ppi Pengelola penuh: kelola pengguna, ruangan, item, assign ruangan ke petugas, serta menyetujui/menolak inspeksi.
Supervisor
supervisor Menyetujui/menolak inspeksi, melihat semua ruangan dan analitik. Tidak bisa mengelola pengguna & data master.

3. Login & Akun

Masuk, keluar, dan mengganti password

🔓 Melakukan Login

  1. Buka alamat aplikasi di browser (misal http://localhost:8080). Anda akan diarahkan ke halaman Login.
  2. Isi kolom Username dan Password sesuai akun Anda.
  3. Klik tombol Masuk. Jika berhasil, Anda masuk ke halaman Dashboard.
⚠️
Jika muncul pesan “Invalid credentials”, periksa kembali username/password, atau hubungi Admin PPI untuk reset password. Akun yang dinonaktifkan juga tidak bisa login.

🔑 Mengganti Password Sendiri

  1. Klik tombol Ganti Password di pojok kanan atas (dekat nama pengguna).
  2. Isi Password Lama, Password Baru (minimal 6 karakter), dan Konfirmasi Password Baru.
  3. Klik Simpan. Klik Generate untuk membuat password acak yang kuat.
  4. Password berhasil diubah — gunakan password baru pada login berikutnya.

🚪 Keluar (Logout)

Klik tombol Keluar di pojok kanan atas. Sesi akan ditutup dan Anda kembali ke halaman login. Selalu logout saat selesai menggunakan komputer bersama.

5. Ruangan

Mengelola daftar ruangan dan item yang diperiksa di dalamnya

➕ Menambah Ruangan

  1. Buka menu Ruangan di sidebar.
  2. Klik tombol + Tambah Ruangan di kanan atas.
  3. Isi Nama Ruangan (contoh: UGD, ICU, Kamar Operasi), lalu klik Simpan.

✏️ / 🗑️ Mengedit & Menghapus Ruangan

  1. Pada baris ruangan, klik tombol Edit untuk mengubah nama, atau Hapus untuk menonaktifkan.
  2. Konfirmasi dengan OK saat dialog muncul. Data yang dihapus menjadi nonaktif, bukan terhapus permanen.
💡
Setiap ruangan menampilkan badge nama item yang menjadi tanggung jawabnya — hasil pemetaan di tombol Item.

📋 Menentukan Item yang Diperiksa di Ruangan (Admin)

  1. Klik tombol Item pada baris ruangan yang diinginkan.
  2. Centang item yang harus diperiksa di ruangan tersebut.
  3. Gunakan tombol ▲/▼ (Naik/Turun) di sebelah item yang dicentang untuk mengatur urutan inspeksi (urutan ini akan dipakai di aplikasi Android).
  4. Klik tombol Item pada ruangan lain untuk menambah/mengurangi pemetaan item-nya. Perubahan tersimpan otomatis.
⚠️
Tombol Item hanya muncul untuk akun Admin PPI. Supervisor/Inspector hanya melihat daftar ruangan.
📋

6. Item Inspeksi

Mengelola item penilaian kebersihan (skor 0–2)

Item adalah aspek yang dinilai saat inspeksi, misalnya Kebersihan Tangan, Penggunaan APD, Pengelolaan Limbah Medis, Sterilisasi Alat, dan lain-lain.

➕ Tambah Item
Klik + Tambah Item → isi nama → Simpan.
✏️ / 🗑️ Edit / Hapus
Tombol Edit / Hapus pada baris item.
🏥 Tombol Ruangan
(Admin) atur di ruangan mana saja item ini diperiksa — hasilnya tampil sebagai badge di tabel.
💡
Item yang sudah pernah dipakai dalam inspeksi tersimpan sebagai snapshot nama — mengganti nama item tidak mengubah data inspeksi lama.
✅

7. Inspeksi

Daftar, filter, dan pencarian inspeksi

📋 Melihat Daftar Inspeksi

Menu Inspeksi menampilkan tabel berisi Tanggal, Ruangan, Status, jumlah Item, dan tombol Detail.

StatusLabelArti
MenungguPENDINGDikirim inspector, belum disetujui — perlu aksi Admin/Supervisor
DisetujuiAPPROVEDSudah disetujui dan dihitung dalam analitik
DitolakREJECTEDDitolak dengan alasan tertentu

🔎 Filter & Pencarian

  1. Tab status di atas tabel: Semua / Menunggu / Disetujui / Ditolak. Secara default menampilkan Menunggu.
  2. Lihat semua ruangan: centang untuk menampilkan inspeksi semua ruangan (khusus Admin/Supervisor). Inspector hanya melihat ruangannya sendiri.
  3. Kotak Cari inspeksi... untuk pencarian global berdasarkan kata kunci.
  4. Klik header kolom untuk mengurutkan; gunakan pagination di bawah tabel.
🔍

8. Detail Inspeksi & Persetujuan

Menyetujui/menolak dan memeriksa hasil inspeksi

👀 Membuka Detail

Klik tombol Detail pada baris inspeksi. Halaman menampilkan: nama ruangan, tanggal & jam, status, tabel item penilaian, dan foto dokumentasi.

Skor 0
0 — Berisiko tidak sesuai standar
Skor 1
1 — Minor kurang sempurna
Skor 2
2 — Sesuai Standar baik

✅ Menyetujui Inspeksi (Admin/Supervisor)

  1. Buka inspeksi berstatus Menunggu.
  2. Periksa nilai tiap item dan foto dokumentasi (klik thumbnail untuk melihat foto besar).
  3. Klik tombol Setujui, konfirmasi OK. Status berubah menjadi Disetujui dan masuk ke perhitungan analitik.

❌ Menolak Inspeksi (Admin/Supervisor)

  1. Klik tombol Tolak.
  2. Isi Alasan penolakan di jendela pop-up (wajib diisi).
  3. Klik Tolak. Alasan ditampilkan di halaman detail sebagai catatan merah.
⚠️
Inspeksi yang ditolak tidak dihitung dalam skor analitik. Inspector harus memperbaiki dan mengirim ulang inspeksi.
👥

9. Pengguna (Khusus Admin PPI)

Kelola akun, reset password, dan assignment ruangan

➕ Menambah Pengguna Baru

  1. Buka menu Pengguna → klik + Tambah Pengguna.
  2. Isi Username, Nama Lengkap (opsional), dan Password (wajib untuk pengguna baru).
  3. Pilih Role: Admin PPI / Supervisor / Inspector.
  4. Klik Simpan. Beri tahu pengguna baru username & password awal.

✏️ Edit, Nonaktifkan, & Reset Password

  1. Edit: ubah username, nama, role, atau status aktif/nonaktif.
  2. Reset PW: atur password baru secara manual atau klik Generate untuk password acak 12 karakter.
  3. Hapus: menonaktifkan akun (user tidak bisa login lagi).
💡
Reset password otomatis mencabut semua sesi aktif pengguna — ia harus login ulang dengan password baru.

🏥 Badge Ruangan di Tabel Pengguna

Setiap baris pengguna menampilkan badge nama ruangan yang menjadi tanggung jawabnya (maksimal 3 badge, sisanya ditandai +N). Klik tombol Ruangan untuk mengelolanya.

➕➖ Menambah & Menghapus Ruangan pada Pengguna (Admin)

  1. Klik tombol Ruangan pada baris pengguna (selain Admin PPI).
  2. Untuk menghapus: klik tanda × pada badge ruangan yang di-assign. Badge langsung hilang setelah proses selesai.
  3. Untuk menambah: pilih ruangan pada dropdown Tambah Ruangan, lalu klik + Tambah. Badge ruangan muncul di daftar assign.
💡
Peran penting: Inspector hanya bisa mengirim inspeksi untuk ruangan yang di-assign padanya. Pastikan assignment ruangan benar sebelum inspector bertugas.
👤

10. Kinerja Inspector

Monitoring produktivitas petugas per bulan
  1. Buka menu Kinerja Inspector.
  2. Pilih bulan pada input tanggal bulan di kanan atas (format YYYY-MM).
  3. Setiap inspector ditampilkan dengan avatar inisial, nama, jumlah inspeksi yang disetujui, badge ruangan tanggung jawabnya, dan bar perbandingan terhadap inspector paling produktif.
💡
Angka dihitung dari inspeksi berstatus APPROVED saja — inspeksi PENDING/REJECTED tidak dihitung.
📈

11. Analitik (Admin & Supervisor)

Evaluasi kualitas kebersihan per ruangan & item

📉 Ruangan dengan Skor Terendah

  • Menampilkan 3 ruangan dengan rata-rata skor terendah pada bulan terpilih.
  • Warna bar menunjukkan tingkat kesehatan: merah <60%, kuning 60–79%, hijau ≥80%.
  • Skor dihitung dari total inspeksi disetujui bulan tersebut.

🔴 Item Paling Sering Bermasalah

  • Item dengan skor 0 (Berisiko) paling sering muncul — prioritas perbaikan.
  • Contoh data seed: Pengelolaan Limbah Medis, Kebersihan Lingkungan, Ketersediaan Sabun & Handuk.
💡
Gunakan halaman ini dalam rapat evaluasi bulanan: tentukan ruangan yang perlu perhatian dan item yang harus diperbaiki bersama tim.

🎯 Skenario A — Menyiapkan Sistem Baru

  1. Login sebagai admin.
  2. Menu Ruangan → tambah semua ruangan (UGD, ICU, Rawat Inap, dll).
  3. Menu Item Inspeksi → tambah semua item penilaian.
  4. Di halaman Ruangan, klik Item per ruangan dan centang item yang berlaku.
  5. Menu Pengguna → tambah akun supervisor & inspector, lalu klik Ruangan untuk menetapkan tanggung jawab tiap inspector.
  6. Bagikan kredensial & alamat server ke petugas; minta mereka segera ganti password.

🎯 Skenario B — Siklus Inspeksi Harian

  1. Inspector membuka aplikasi Android, memilih ruangan yang di-assign, menilai tiap item (0/1/2), memotret bukti, lalu mengirim inspeksi.
  2. Admin/Supervisor membuka menu Inspeksi (default filter “Menunggu”), periksa detail + foto.
  3. Jika sesuai → Setujui. Jika tidak → Tolak dengan alasan.
  4. Inspeksi yang ditolak → inspector kirim ulang setelah perbaikan.
  5. Data disetujui otomatis memperbarui Dashboard, Analitik, dan Kinerja Inspector.

🎯 Skenario C — Evaluasi Bulanan

  1. Buka Analitik, pilih bulan berjalan.
  2. Identifikasi ruangan dengan skor terendah untuk dijadikan target perbaikan.
  3. Identifikasi item paling sering bermasalah untuk pelatihan/sosialisasi petugas.
  4. Buka Kinerja Inspector untuk membandingkan produktivitas tim.

13. Aplikasi Android (Inspector)

Alur kerja petugas lapangan

🔄 Sinkronisasi & Mode Offline

  • Android sinkronisasi data (ruangan, item, user-room, foto) saat tersambung internet.
  • Jika jaringan hilang, aplikasi menyimpan pekerjaan dan mengirim ulang otomatis saat online kembali.

📸 Mengirim Inspeksi

  1. Login dengan akun inspector.
  2. Pilih ruangan yang di-assign ke Anda.
  3. Nilai setiap item (skor 0 = berisiko, 1 = minor, 2 = sesuai standar) dan lampirkan foto dokumentasi.
  4. Kirim inspeksi. Status menjadi Menunggu hingga disetujui Admin/Supervisor.
💡
Foto yang keliru bisa diganti — inspector pemilik inspeksi atau Admin/Supervisor dapat mengunggah ulang foto (fitur Replace Photo, ADR-0012).

14. FAQ & Troubleshooting

Masalah umum dan solusinya

🔒 Tidak bisa login

  • Periksa username/password (sensitif huruf besar/kecil).
  • Hubungi Admin PPI untuk reset password di menu Pengguna.
  • Akun mungkin dinonaktifkan oleh admin.

👁️ Menu / tombol tidak muncul

  • Setiap peran punya kewenangan berbeda (lihat Bagian 2). Tombol Item, Ruangan (di Pengguna), dan Analitik hanya untuk peran tertentu.

📷 Foto tidak tampil / gagal upload

  • Periksa koneksi internet dan ukuran file (maksimal mengikuti konfigurasi server, default 10 MB di nginx).
  • Foto dilindungi autentikasi — pastikan sesi masih aktif.

📤 Inspeksi tidak bisa dikirim (Android)

  • Pastikan ruangan sudah di-assign ke akun Anda oleh Admin (menu Pengguna → Ruangan).
  • Hindari mengirim duplikat untuk ruangan/tanggal/jam yang sama — sistem menolak duplikat.

📊 Angka dashboard/analitik tidak berubah

  • Analitik hanya menghitung inspeksi APPROVED.
  • Data diproses lewat background job — tunggu beberapa saat, lalu muat ulang halaman.
